Everything a plan set needs

Built around the way drawings actually get reviewed in the field and the office.

Measure to scale

Set the scale from the drawing (or let FieldMark detect it), then measure lengths, arc lengths, radii, areas and angles. Snap to geometry for repeatable numbers.

Redline and markup

Clouds, callouts, arrows, freehand, text, highlight, underline and strikeout — with a markup list you can filter and step through.

Takeoff-ready totals

Measurements collect into a panel you can review per page or per sheet, so quantities come off the drawing instead of a separate spreadsheet.

Organize a set

Merge, split, reorder, rotate and delete pages. Number a set and apply watermarks or stamps across every sheet at once.

Sign and fill

Fill AcroForm fields, drop signatures, initials and dates, then flatten. Certified PKI digital signatures are supported too.

Text recognition

Run OCR on a scanned sheet so you can search and select text on drawings that arrived as flat images.

Compare revisions

Overlay two revisions of the same sheet and see what moved, side by side or superimposed.

Big sets stay fast

Built on a virtualised viewer, so a several-hundred-page set scrolls and zooms without loading the whole thing into memory.

What it looks like

Dark "drafting table" by default, with a light blueprint-vellum theme a keystroke away.

Your drawings stay yours

FieldMark makes no network requests while you use it. There is no account, no sync, no cloud storage, no analytics inside the app and no crash reporting. Files you open are read on your own device and never uploaded — including in the browser version, which does all its work locally.

The single exception is deliberate and optional: the desktop app can check GitHub for a newer release when you ask it to. Nothing about your documents is involved in that request.

This page is static and carries no analytics or third-party scripts either. The source for both the app and this site is public on GitHub.

Questions

Is it really free?

Yes. MIT licensed, no paid tier, no trial period, no feature gates. You can read the source, build it yourself, and fork it.

Does the browser version upload my PDF anywhere?

No. It parses and edits the file entirely in your browser. There is no server to upload to — the site is static files.

Can I open my marked-up file in another PDF app?

Yes. Markups export as standard PDF annotations and measurements are written into PDF user space, so other readers show them correctly, including on rotated pages.

How big a set can it handle?

Large ones. Pages render on demand rather than all at once, so several-hundred-page sets stay responsive.

Why does Windows or macOS warn me on first launch?

The builds are not paid code-signing-certificate signed. The installers come straight from the public GitHub Actions build, and the steps to get past the warning are in the README.

I found a bug / I want a feature.

Please open an issue — there is a Send feedback item in the app's Help menu that pre-fills your version and platform, or you can go straight to the issue tracker.
